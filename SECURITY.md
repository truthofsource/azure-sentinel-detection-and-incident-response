# Security and publication boundary

This public reference contains selected implementation code, fictional resource bindings, original selected tests and local fixture evidence. It contains no real employee/client records, private incident contents, access tokens, passwords, settings dumps or operational state.

The local tests and demo need no Azure login. The adapter is included for review, but the repository does not supply the complete live Function host or commissioning configuration. Cloud examples start disabled and can incur charges if separately deployed. A passing local/model/mock test does not prove live identity, DNS, query authorization, delivery, containment or compliance.

Use fresh reviewed targets and a protected state store for any adaptation. Keep real source records, state, plans, credentials and incident exports out of Git. Report a suspected exposure privately to the repository owner; do not attach sensitive material to a public issue.
